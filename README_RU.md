# Interstellar Experience 0.5.0 — First-person flight prototype

Minecraft Java 1.21.11 / Fabric / Java 21.

## Что делает эта сборка

Эта версия переводит запуск Тессеракта из отдельного меню в режим полёта от первого лица в одиночном мире:

- `O` — включить/выключить режим свободного полёта;
- `WASD` — движение в режиме полёта;
- `Пробел` — вверх;
- `Shift` — вниз;
- мышь — осмотреться от первого лица;
- `P` — сохранить снимок области мира в истории;
- `R` — повторить звуковую фразу.

При входе сохраняются исходные настройки полёта, гравитации и перспективы. При выходе они восстанавливаются. Режим намеренно ограничен одиночной игрой и не активируется на многопользовательских серверах.

## Честное ограничение

0.5.0 — первый этап управления полётом от первого лица по настоящему Minecraft-миру. Это ещё не финальная кинематографическая сцена Интерстеллара: повторяющиеся объёмные копии ландшафта, Гаргантюа и специальные пространственные эффекты пока не встроены в обычный игровой рендер. Старый экранный 3D-прототип остаётся в исходниках, но клавиша `O` больше не открывает его.

## Сборка через GitHub Actions

1. Загрузите содержимое архива в корень репозитория, заменив файлы проекта.
2. Сделайте Commit changes в ветку `main`.
3. Откройте Actions и дождитесь успешной сборки.
4. Скачайте Artifact `InterstellarExperience-Fabric-1.21.11-v0.5.0`.
5. Извлеките основной JAR и положите его в `.minecraft/mods`.

Перед тестированием сделайте резервную копию мира. Вход в режим поддерживается только в одиночном мире.


## Версия 0.6.0 — подключение сцены

Клавиша O открывает полноэкранную 3D-сцену Тессеракта. Сцена использует цветовые 3D-снимки блоков вокруг игрока и размещает несколько повторяющихся пространственных фрагментов в коридоре. P сохраняет новый снимок, стрелки влево/вправо переключают сохранённые моменты, R воспроизводит цитату, Esc или O закрывает сцену.

Важно: это пока кинематографическая сцена внутри интерфейса, а не полноценная свободная 3D-камера от первого лица, летящая сквозь копии мира. Визуальные фрагменты — упрощённые цветовые воксели, не полные копии блоков с текстурами и состояниями.
